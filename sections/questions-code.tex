\subsection*{Problem 4.1}

A short framing sentence that explains where the code comes from
and why the student is looking at it.

\begin{lstlisting}[language=Python]
import sqlite3

def login(username, password):
    conn = sqlite3.connect("users.db")
    cursor = conn.cursor()

    query = "SELECT * FROM users WHERE username = '" \
            + username + "' AND password = '" + password + "'"
    cursor.execute(query)
    result = cursor.fetchone()

    conn.close()
    return "Login successful" if result else "Login failed."
\end{lstlisting}

\vspace{2mm}

Answer the following:

\begin{enumerate}[label=(\alph*)]

\item Identify the defect in the code above and name it precisely.
Explain what an attacker (or a user) can make this code do.

\vspace{35mm}

\item Trace the code with a specific hostile or edge-case input.
Write out the resulting query / state / output.

\vspace{40mm}

\item Rewrite the function so the defect is fully removed.
Your rewrite must remain functionally equivalent for valid input.

\vspace{60mm}

\end{enumerate}
